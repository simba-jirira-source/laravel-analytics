Use this pack after `laravel-analytics` is public on GitHub and Packagist.

## Recommended location

Copy this directory into:

```text
docs/cursor/post-release/
```

## Order

1. `POST_RELEASE_IMPROVEMENT_PLAN.md`
2. `versions/V0_6_0_FOUNDATION.md`

Never implement more than one roadmap version at once. The prompts do not authorize Cursor to create Git tags, GitHub Releases, or publish releases automatically.
